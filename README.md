# Ideka

Universal mapper for project and lore. / Éditeur visuel pour cartographier des univers narratifs (blocs, bacs, connexions).

## Télécharger / Download

Va dans **[Releases](../../releases/latest)** (colonne de droite de cette page), puis télécharge le fichier de ton système :

| Système | Fichier |
|---|---|
| Windows | `Ideka_…_Windows_x64-setup.exe` |
| Mac récent (puce Apple M1, M2…) | `Ideka_…_macOS_AppleSilicon.dmg` |
| Mac Intel | `Ideka_…_macOS_Intel.dmg` |
| Linux | `Ideka_…_Linux_x64.AppImage` |

Les autres fichiers (`.zip`, `.tar.gz`, `.sig`, `latest.json`) servent aux **mises à jour automatiques** : inutile de les télécharger.
The other files are used for automatic updates: no need to download them.

Ensuite, Ideka vérifie les mises à jour à chaque lancement et propose de se mettre à jour tout seul.

## Installation

**Windows.** Lance le fichier `…_Windows_x64-setup.exe`. L'installation se fait dans ton profil, sans droits administrateur.
Si Windows affiche « Windows a protégé votre ordinateur » (l'installeur n'est pas encore signé par un éditeur reconnu),
clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.

**Mac.** Ouvre le `.dmg` et glisse Ideka dans Applications. L'application n'est pas encore « notarisée » par Apple : au premier
lancement, fais un **clic droit sur Ideka, puis Ouvrir** (sous macOS 15 et plus : Réglages Système, Confidentialité et sécurité,
« Ouvrir quand même »). macOS 12.3 ou plus récent recommandé.

**Linux.** Rends le fichier exécutable (clic droit, Propriétés, Exécutable, ou `chmod +x Ideka_*.AppImage`), puis lance-le.
Sur Ubuntu récent, il faut parfois installer `libfuse2`.
